# Documentation

Reference material for every mod in this collection. Each category covers what
the mod adds, how to install it, and the exact configuration files it reads.

::card-group

:::card{title="CultTweaker" icon="i-lucide-wand" to="/docs/culttweaker"}
The world editor, custom dungeons, player and follower spines, weapons, NPC
quests, enemies, structures, and the modding API.
:::

:::card{title="Supercharged Series" icon="i-lucide-zap" to="/docs/supercharged"}
Supercharged Tarots and Supercharged Followers: card lists, rally mechanics,
class boosts and prestige levels.
:::

:::card{title="CotL MiniMods" icon="i-lucide-boxes" to="/docs/minimods"}
Custom structures, follower roles, rituals, commands and the Trial of the Gods
difficulty system.
:::

::

## Before you start

Every mod here runs on [BepInEx](https://thunderstore.io/c/cult-of-the-lamb/p/BepInEx/BepInExPack_CultOfTheLamb/)
and needs [COTL_API](https://thunderstore.io/c/cult-of-the-lamb/p/xhayper/COTL_API/).
Install those first, then drop the mod folder into `BepInEx/plugins`.

Questions, bug reports and modding talk all happen in the
[modding Discord](https://discord.gg/MUjww9ndx2).
